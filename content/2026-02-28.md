## i3

A few years ago I ran Manjaro w/ i3 as my daily driver. After the initial learning curve, the sheer speed a tiling window manager provides is second to none.

One of my favorite features was the [scratchpad](https://i3wm.org/docs/userguide.html#_scratchpad).  Scratchpad allowed you to maintain the tiling nature of the workspace but still have a toggleable overlay(s) available.

I most frequently used this to create a scratchpad terminal (I used `urxvt` at the time because of font support and speed).

```bash
# move the currently focused window to the scratchpad
bindsym $mod+Shift+minus move scratchpad

# Show the next scratchpad window or hide the focused scratchpad window.
# If there are multiple scratchpad windows, this command cycles through them.
bindsym $mod+minus scratchpad show
```

<https://ghostty.org/docs/config/reference#quick-terminal-position>

```text
quick-terminal-position = center
quick-terminal-animation-duration = 0
keybind = global:super+`=toggle_quick_terminal
quick-terminal-size = 70%,70%
```

## The result

combine w/ tmux and neovim to provide:

- tab 1: todo list
- tab 2: work log
- tab 3: k9s
- tab 4+: general terminal work

## Limitations

- resizing when monitor / screen layout changes
- could fix by setting https://ghostty.org/docs/config/reference#quick-terminal-screen to `macos-menu-bar`
- press 3x on fresh ghostty boot
